# Historical upstream reference media

This folder retains historic images from the upstream **PocketPal AI**
repository strictly for source attribution and historical comparison. Images
here are *not* TARS-AI icons, store screenshots, marketing copy or runtime
artwork. They must not be redistributed as TARS-AI promotional materials.

The TARS-AI runtime uses its own brand mark, Android vector launcher, iOS
TARS launcher image, metallic boot artwork and TARS onboarding graphics.
The store screenshot directory has been cleared: create fresh screenshots
from a tested TARS-AI build before publication.

The upstream project is separately credited in the root README and LICENSE.
