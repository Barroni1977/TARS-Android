TARS-AI — PERSONAL, LOCAL-FIRST INTELLIGENCE

TARS-AI lets you download compatible GGUF language models and run text chat directly on your Android device. After downloading a model, local inference can work without a cloud AI service or an internet connection.

FEATURES
• Distinctive metallic TARS-inspired interface with green diagnostics and amber accents
• Local language model selection, download and management
• Text chat with models that fit your device
• Model and inference parameter controls
• Optional voice and advanced integrations, depending on installed models and device support
• Session management, local AI profiles and benchmarking

HOW OFFLINE WORKS
Install a model while connected to the internet. Local text inference can then run on your device even when offline. Some features use a connection, including model downloads, optional web search, remote services, feedback and external accounts. Available voice methods have their own requirements. Review feature settings and permissions before use.

MODEL REQUIREMENTS
Model compatibility, speed and memory requirements vary by device, model size and quantization. Start with a small model and test performance before downloading larger ones. AI output can be incorrect; verify important information.

INDEPENDENT OPEN-SOURCE DEVELOPMENT
TARS-AI is an independent fork based on PocketPal AI and other open-source components, including llama.cpp and llama.rn. See the application's open-source notices and repository for required attribution.
